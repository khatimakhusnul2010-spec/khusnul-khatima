Selamat Datang di Website Saya

Ini adalah website multipage sederhana dengan tema Profil Mahasiswa, dibuat menggunakan HTML dan CSS. Gunakan menu navigasi di atas untuk melihat halaman Profil dan Kontak.

Tentang Website Ini

Website ini terdiri dari tiga halaman terpisah (index.html, profil.html, kontak.html) yang saling terhubung melalui hyperlink, dan menggunakan satu file CSS (style.css) yang sama untuk seluruh halaman agar tampilan tetap konsisten.
